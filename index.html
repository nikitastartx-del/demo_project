Fixing a product card that breaks on mobile screens

A common responsive layout bug: a product card with a fixed width and oversized inner elements pushes past the edge of a phone screen, creating horizontal scrolling and clipping the button. Below you can compare the broken version with the corrected one.

What was fixed

  1. 1

    Prevented horizontal overflow

    The card width changed from a hard-coded value to max-width: 100%, so content can no longer extend past the viewport and cause horizontal scrolling.

  2. 2

    Improved responsive spacing

    Fixed pixel margins were replaced with fluid padding and media queries, keeping comfortable spacing on both wide and narrow screens.

  3. 3

    Made the button fit smaller screens

    The button now uses width: 100% with a flexible container instead of a fixed width, so it always fits inside the card.
